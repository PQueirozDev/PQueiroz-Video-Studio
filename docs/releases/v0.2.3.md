### Presets compartilháveis
- **Exportar preset** (Configurações › Presets): gera um arquivo `.pqpreset` que pode levar junto o seu sistema de edição — CLAUDE.md, Modelo edicao, skills de vídeo do Claude e, se quiser, as músicas.
- **Importar** por arquivo, por link ou pela nova galeria de **presets da comunidade**. As skills são instaladas no Claude Code sem sobrescrever as que você já tem.
- Num computador novo, o fluxo importado vira o sistema de edição automaticamente.

### Correções
- Num computador sem a pasta `E:\aqc`, a primeira tela não mostra mais erro de "pasta não encontrada": o sistema de edição agora é opcional, com o botão **Importar preset**.
- O chat com o Claude não tenta mais acessar uma pasta de sistema de edição que não existe.
